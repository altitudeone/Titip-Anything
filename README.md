# 🍔 Titip Anything - Office Order & Titip System

A streamlined web-based ordering & errand tracking system designed to simplify group food orders and errands using Google Apps Script & Google Sheets.


💡 Background & Problem Statement
Aplikasi ini dibuat untuk menyelesaikan masalah ketidakpraktisan saat nitip makanan/belanjaan di lingkungan kantor. Masalah utama yang sering terjadi:
1. Rincian pesanan tercecer di grup chat WhatsApp.
2. Lupa nominal uang yang harus ditalangi/dibayar.
3. Sulit memantau status pesanan mana yang belum atau sudah dibelikan.


## ✨ Key Features
- **📝 Form Pesan Titipan:** Pemesan tinggal menginput nama, lokasi/lantai, pesanan, dan metode bayar (Cash/QRIS).
- **📋 Real-Time Order Management:** Tab khusus untuk "Yang Belanja" untuk melihat daftar pesanan yang pending secara real-time.
- **✅ Selesaikan Pesanan:** Fitur input harga asli & catatan saat belanjaan selesai dibeli.
- **📊 Google Sheets Synchronized:** Semua data tersimpan rapi dan otomatis memperbarui status pesanan dari `Pending` menjadi `Selesai`.


## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript.
- **Backend:** Google Apps Script.
- **Database:** Google Sheets.
